You (kubectl)

You describe what you want — "3 copies of this app" — in a YAML file, and send it to the cluster. You never say how to do it, only what the end result should look like.

Control Tower (Control Plane)

The brain of the cluster. The API Server receives your request, etcd remembers it, and the Scheduler decides which ship has room to run it.

The Ship (Worker Node)

A real machine that actually runs your app. kubelet is the dockworker following the tower's orders, and containerd is what actually starts each container.

Crates (Pods)

Each crate is one running copy of your app — a Pod. Every crate gets its own real network address, so it can be reached directly, and can talk to its neighbors.

The Roads (Calico / CNI)

The dashed lines connecting crates are the cluster's network layer. It gives every pod a real, routable address — no extra setup needed for one crate to reach another.

Self-Healing

If a crate falls overboard (a container crashes), kubelet notices the ship no longer matches the tower's order and quietly loads a replacement — without anyone having to ask.
